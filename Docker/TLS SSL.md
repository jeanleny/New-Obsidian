Secure Sockets Layer
Transport Layer Security
Theses are protocols that uses both message authentication codes.
Its a cryptographic technique that checks message intergrity and authenticity.

We often talk about symmetric encryption.
Its means that **each sides uses the same encryption/decryption key to transfer data**

This way, only the server can read the connections.

It works with **SSL certificates**.
Its basically, a digital ID for the server.

It contains :
- server public key
- domain name
- signature from a trusted authority

**2 types of certificates**
1. *TRUSTED* : used by companys(Let's encrypt), browsers trust it automatically
2. *SELF SIGNED* : Generated by yourself, browser shows warning.
