
Cela représent un ensemble de données enregistrées sur des supports virtuels.
Ces bases peuvent êtres intérrogées et manipulées par un ou plusieurs utilisateurs avec des rôles/accès variables.

Dans une base de données informatisée, on stocke des ensembles **d'éléments**, eux mêmes constituées de plusieurs **caractéristiques**(nom, prix, image, description).

On les classe selon un modèle spécifique.
Un **modèle** définit comment sont stockées, agencées et comment leurs accéssibilitées sur les données.
