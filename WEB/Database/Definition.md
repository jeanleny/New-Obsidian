# Qu'est ce qu'une base de données ?

Une base de données caractérise un support regroupant un ensemble organisé d'informations afin d'en faciliter l'exploitation(ajout, mise a jour, suppression, recherche de données)

Le terme base de données désigne simplement un endroit regroupant des informations, un dictionnaire ou cahier de comptabilité sont des base de données physiques.

En informatique, cela peut-être un dossier de fichier, un fichier excel.
Il y a plusieurs formats de fichier notamment le .csv (Comma.Separated.Values), qui permet de regrouper les données sous formes de tableau.
Mais pour le travail du web, nous allons plutôt utiliser les .db, .sqlite...
