HTTP stand for Hyper Text Transfer Protocol.
Its the foundation of data communication on the web.
It allows web clients and servers to exchange informations.
This defines how data, web pages, images and videos are transferred over the internet.

An HTTP request is a message sent by a client (typically a browser or mobile app) to a server, asking for a specific resource or action.

HTTP follows a request-response system, meaning that the clients sends request to the server and the server responds with the requested content depending on what requested.

There are 4 mains part in the http request.

1. The [[Request Line]]
2. [[Headers]]
3. [[Body]]
4. [[Query Parameters]]
